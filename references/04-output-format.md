# 04 · 输出规范（只有一段 JSON）

## 1. 结构

```jsonc
{
  "riskLevel": "高风险",          // 整体等级：高风险 | 中风险 | 低风险 | 通过
  "summary": "共5项风险。...",     // 风险总结，≤100 字
  "checkRes": [                   // 逐条结果，与 items 一一对应、顺序一致
    {
      "fieldCode": "TPM-豫HN-001",   // 原样保留规则集的 fieldCode
      "fieldName": "经销商名称",      // 原样保留规则集的 fieldName
      "riskLevel": "中风险",          // 高风险 | 中风险 | 低风险 | 通过
      "auditDesc": "合同中经销商名称为'…'，表单中为'…'，不一致"
    }
  ]
}
```

字段纪律：

| 字段 | 纪律 |
|------|------|
| `riskLevel`（外层） | 四个枚举之一；= 所有 `checkRes[].riskLevel` 的最高档 |
| `riskLevel`（内层） | 四个枚举之一；只能来自该条 `judgeRule` |
| `summary` | ≤100 字；全通过时固定 `暂无风险，无需关注。` |
| `fieldCode` / `fieldName` | 原样复制规则集，不改写、不翻译、不补编号 |
| `checkRes` 长度 | **等于 `items` 长度**，顺序一致，一条不漏一条不多 |
| `auditDesc` | `通过` 时为空字符串 `""`；不一致时为中文短句 |

## 2. `summary` 生成规则

### 2.1 全部通过

```
summary = "暂无风险，无需关注。"
```

### 2.2 存在风险

固定句式，按 **高 → 中 → 低** 顺序拼接；计数为 0 的档位**整段不写**：

```
共{N}项风险。{档位}{n}项：{字段名、字段名、字段名}不一致；{档位}{n}项：{字段名}不一致。
```

- `{N}` = `checkRes` 中 `riskLevel ≠ 通过` 的条数。
- `{档位}` = `高风险 / 中风险 / 低风险`。
- 字段名用 `fieldName` 原文，多个之间用顿号分隔，**整组末尾统一带一个「不一致」**。
- 最后一组用句号收尾，前面各组用分号。

示例（`[中风险, 低风险, 低风险]`）：

```
共3项风险。中风险1项：经销商名称不一致；低风险2项：合作方式、进店价不一致。
```

### 2.3 100 字预算

完整列表超 100 字时，按下列顺序降级，直到 ≤100 字：

```
① 去掉中/低风险组的字段名，只留数量 → "中风险3项"
② 高风险组若仍超长，字段名最多保留 5 个，其余用"等"字收尾
③ 仍超长（极端情况）→ 只写 "共{N}项风险。高风险{n}项；中风险{n}项；低风险{n}项。"
```

**高风险的字段名始终保留**（这是要人立刻处理的部分）。

### 2.4 字数怎么算

按中文字符数计（含标点、数字、字母），不含首尾空白。生成后自查：超 100 字就按 §2.3 降级。

## 3. `auditDesc` 模板

按情形套用，**不要自由发挥**：

| 情形 | `auditDesc` |
|------|-------------|
| 一致 / 不判断 | `""`（空字符串） |
| 单值·合同有值且不一致 | `合同中{fieldName}为'{合同值}'，表单中为'{表单值}'，不一致` |
| 单值·合同侧为空 | `合同中{fieldName}为空，表单中为'{表单值}'，不一致` |
| 单值·表单侧为空 | `合同中{fieldName}为'{合同值}'，表单中为空，不一致` |
| 表格·合同侧为空（表单有信息） | `合同中{fieldName}为空，表单中包含产品{fieldName}信息，不一致` |
| 表格·合计类·合同侧为空 | `合同中{fieldName}为空，表单中{fieldName}合计为{值}，不一致` |
| 表格·有差异行 | `合同与表单{fieldName}不一致：{产品}（合同{合同值}，表单{表单值}）` |

补充约定：

- 单值用**中文单引号** `'…'` 包住值；表格类用**全角括号** `（…）` 包住单行差异。
- 多个差异产品用顿号分隔；超过 3 个时只列前 3 个，末尾加 `等{N}项`。
- 日期按 `outputDesc` 格式写：`2024年07月23日-2025年06月30日`。
- 数值写归一化后的形式：`66`、`68`（不要 `66.00`、`¥66`）。
- 单位确实不同的（零售价），在描述里点明：`勇闯天涯（合同6元/瓶，表单84元/件即7元/瓶）`。
- 不写证据出处、不写置信度、不写建议动作 —— 这些不在这份输出里。

## 4. 输出纪律

```
只输出 JSON 文本：
  ✓ 2 空格缩进
  ✓ 前后不加任何说明文字
  ✓ 不用 ``` 代码围栏包住（便于调用方直接 json.loads）

禁止：
  ✗ 审计报告 / 风险矩阵 / 逐条明细表格
  ✗ "以下是审计结果：" 之类的前缀
  ✗ 需人工处理清单、口径确认单、补充观察
  ✗ 证据附件、置信度、建议动作
```
