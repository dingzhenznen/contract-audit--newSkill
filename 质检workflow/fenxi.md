  没有 reference 时的典型翻车场景

  - 老报账单只有 报账信息-开户名，md 没写别名 → 户名为空 → 假 HOLD 或假 PASS。
  - 合同户名带“（盖章）”或空格，md 没写清洗 → 本来一致却判 HOLD。
  - 供应商名称里含“金沙酒业”（付款方），md 没写过滤 → 把付款方当成供应商。
  - 多份补充协议，md 只说“合并” → agent 直接字符串拼接 → 名称和账号对不上。
  - 没有补充协议，md 没说回退合同 → agent 报“无合同信息” → 假 HOLD。
  - 附件侧字段为空，md 没说该分支“空字段默认无误” → 本来应 PASS 却 HOLD。
  - 输出时写了一段分析报告 → 下游 JSON 解析失败。
